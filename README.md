# 🌱 CropGuard AI

AI-powered crop disease detection using a pretrained deep learning model and Flask.

## 📌 About

CropGuard AI is a web-based application that analyzes images of crop leaves and predicts the most likely disease using a pretrained image classification model.

The user uploads a leaf image through the web interface, the Flask backend sends the image to the AI model, and the system returns the predicted disease along with its confidence score.

## 🚀 How It Works

```text
Leaf Image
    ↓
Image Upload
    ↓
Flask Backend
    ↓
Image Preprocessing
    ↓
Pretrained AI Model
    ↓
Disease Prediction
    ↓
Confidence Score
    ↓
Result Dashboard
```

## 🧠 AI Model

The project uses a pretrained deep learning image-classification model based on EfficientNet-B2.

The model processes the uploaded leaf image and predicts the most likely disease class.

The system currently supports disease classes covering:

- Apple
- Corn (Maize)
- Tomato

The application displays the top predictions along with their confidence scores.

### Main Files

**app.py**
Flask backend that handles image uploads and connects the web interface with the AI model.

**model.py**
Loads the pretrained model, preprocesses images, performs inference, and returns predictions.

**predict.py**
Used to test the AI prediction pipeline directly from Python.

**templates/index.html**
Frontend page for uploading a crop leaf image.

**templates/result.html**
Displays the prediction results and confidence scores.

**static/style.css**
Contains the styling for the web interface.

**requirements.txt**
Lists the Python dependencies required to run the project.

## 💻 Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/CropGuard-AI.git
```

Enter the project directory:

```bash
cd CropGuard-AI
```

Create a virtual environment:

```bash
python3 -m venv venv
```

Activate it:

```bash
source venv/bin/activate
```

Install the required packages:

```bash
pip install -r requirements.txt
```

## ▶️ Run the Application

Start the Flask server:

```bash
python3 app.py
```

Open the application in your browser:

```text
http://127.0.0.1:5000
```

Upload a crop leaf image and click **Analyze Leaf**.
