# 🌱 CropGuard AI

AI-powered crop disease detection using computer vision and a pretrained deep learning model.

## 📌 Overview

CropGuard AI is a web-based application that analyzes images of crop leaves and predicts the most likely disease using a pretrained image classification model.

The project combines:

- Deep Learning
- Computer Vision
- Python
- Flask
- HTML/CSS
- Hugging Face Transformers

The goal is to provide a simple interface where a user can upload a leaf image and receive an AI-generated disease prediction with a confidence score.
